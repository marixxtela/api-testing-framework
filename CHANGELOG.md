## 0.1.0

First publishable version of the framework.

- Target Fastify + Prisma API with REST and GraphQL endpoints, JWT auth, rate limiting.
- Vitest test layer with typed clients, Zod schemas, and Test Data Builders.
- Functional suite covering users, orders, auth, and GraphQL.
- Consumer and provider contract testing with Pact-JS, broker via docker-compose.
- Automatic validation against the OpenAPI spec generated by Fastify.
- Security suite: injection, rate limiting, auth.
- Performance via k6 with thresholds and smoke and load scenarios.
- WireMock and MSW mock servers with failure scenarios.
- GitHub Actions pipeline with Pact Broker publishing and can-i-deploy.
- Documentation: ADRs, architecture, contract testing guide, coverage matrix.
