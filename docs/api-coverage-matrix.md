Update this matrix whenever you add or remove an endpoint, or introduce a new test modality.

## Conventions

- Schema (OpenAPI): validation of the real response against the spec generated by Fastify (`openapi/spec.yaml`). For GraphQL, validation via schema introspection.
- Security: at least one scenario covering injection, malicious payload, missing token, insufficient role, or rate limit.
- Contract consumer: a Pact interaction exists, generated by a representative consumer.
- Contract provider: a state handler exists in the Verifier covering the published interaction.
- Performance: included in `tests/performance/smoke.js` with p95 and error rate thresholds.
- Postman: an equivalent request exists in `postman/collection.json`, runnable via Newman.
